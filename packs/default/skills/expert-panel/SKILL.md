# Expert Panel（多犬专家辩论）

## 流程

### 1. 问题分发
把问题发给 2-3 只犬独立思考。

### 2. 独立思考
每只犬从自己的狗狗视角分析，给出结论 + 证据。

### 3. 交叉辩论
暴露分歧点，每只犬对其他犬的结论给出反馈。

### 4. 收敛
- 共识：直接输出
- 分歧：列出双方论点 + 证据，给 operator 决策
- 行动项：下一步做什么

## WHY 链
每个结论必须有 WHY 链：结论 → 依据 → 证据来源。
