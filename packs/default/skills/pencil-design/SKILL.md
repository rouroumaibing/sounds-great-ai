# Pencil Design（设计文件编辑）

## 流程

### 1. 创建/打开 .pen 文件
- 新建设计文件
- 或打开已有 .pen 编辑

### 2. 设计
- 在 .pen 中布局组件
- 设置样式/交互
- 预览效果

### 3. 导出
- 导出为 React + Tailwind 组件
- 或导出为静态 HTML

## 注意
- .pen 文件是设计源，代码是产物
- 设计变更从 .pen 开始，不从代码回改
