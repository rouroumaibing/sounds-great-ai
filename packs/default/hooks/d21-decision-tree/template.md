## 传球决策树（对标 clowder-ai D21）

下一棒传球决策树（本轮必选其一，缺 = 消息不完整）：先问"下一步谁能做"——

1. **另一个犬种能做** → @句柄（review 完→@author / 修完→@reviewer / merge 完→@愿景守护犬）
2. **等外部条件**（云端 agent / GitHub bot / PR check / CI / 长 build / 外部 webhook——这些不是本地犬，不在 roster，不可 @ 任何本地近似 proxy）
   - 无回调覆盖 → 声明等什么 + 定时轮询
   - 已有结构化回调 → 纯事件驱动，不轮询
   - 要跑本地命令等结果 → 命令托管，完成后自动唤醒
3. **只有 leader 本人才能做** → @leader（硬条件：不可逆操作 / 愿景级决策 / 跨犬僵局）

@leader 不是默认出口——先问"哪只犬能接"。反问式 ping 非法（"要不要 X？"/"同意吗？"）：有立场就自决去做（错了能回滚），没立场根本不该 @。**外部 identity** 永远走选项 2，严禁投射成本地 @句柄。
