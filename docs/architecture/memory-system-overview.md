# Sounds Great AI 记忆系统全景

> **本文的位置**：overview（系统全景是什么）→ 哲学纲领在 `memory-philosophy.md`（为什么这样设计）。

## 六器官

记忆系统不是一个数据库，也不是"自动把旧聊天塞进 prompt"。它是六个相互制约的器官：

### 1. 写入侧

- **谁写**：犬（M17 写入是反射不是命令）
- **何时写**：趁热写，带语境写（M18）
- **写不写**：写入有门槛，门槛偏低（M19）
- **关联**：写入的完成态是"可被沿关系找到"（M20）

### 2. 索引面

- **全文索引**：BM25/FTS，零失真路径（M10）
- **向量索引**：embedding，有损压缩，只站导航位（M11）
- **混合检索**：hybrid = BM25 + vector + RRF fusion

### 3. 召回面

- **检索主权在犬**（M6）：搜什么、信什么、追不追由犬定
- **给数据不给结论**（M7）：候选和 provenance 可以给，判断留给犬
- **排序即注意力分配**（M13）：authority / recency / consumption / MMR

### 4. 消费面

- **push/pull 以提交权分界**（M5）：系统 push 候选提示合法，内容提交必须犬 pull
- **投机不提交**（M8）：预取/预热随便跑，结果只能 stage
- **记忆是数据不是指令**（M2）：不改变规则/权限/身份

### 5. 治理面

- **授权先于寻址**（M1）：可寻址性是授权下的相对属性
- **遗忘是合法权利**（M1）：不是系统缺陷
- **写入带签名**（M16）：仲裁归真相源不归消息
- **时态是义务**（M15）：记忆必须携带时态元数据

### 6. 退役面

- **退役治"仍真但已翻篇"**（M15）：移出活跃召回，不物理删除
- **遗忘语义分层**：结论层 = 物理清除；历史层 = 退役封存
- **关系记忆转入纪念品盒**（M21）

## 记忆分道

| 道 | 内容 | 对应模块 |
|----|------|----------------|
| project | feature specs、决策、教训 | docs/ |
| thread | 对话历史 | threadstore |
| library | 外部知识集合 | library/ |
| taste | 品味导航 | taste lane |
| profile | 关系画像 | profile primer |
| event | 交互事件 | event memory |

分道不斩链（M4）：因果链跨道存在，分道是防混淆，不是斩断跨道引用。

## 三权分离

| 权 | 持有者 | 说明 |
|----|--------|------|
| 提交权 | 犬 | 什么进入推理只能犬定 |
| 候选权 | 系统 | 主动亮出地图边缘是系统补犬盲区的本分 |
| 权威权 | 治理 | authority、隐私、写入与遗忘的规则 |
