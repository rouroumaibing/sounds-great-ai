# Self Evolution（自我进化）

## Scope Guard

operator scope 发散偏离愿景时：
1. 记录 Scope Guard Log（偏离项 + 愿景对照 + 拉回动作）
2. 主动收缩回愿景范围
3. 不等 operator 发现，主动报告

## Process Evolution

同类错误反复出现或 SOP 流程有缺口时：
1. 根因分析（不停留在表面坑）
2. Evolution Proposal（流程改进建议）
3. 更新 SOP / AGENTS.md / 对应 hook

## Knowledge Evolution

有价值的知识/方法论值得沉淀时：
1. Episode Card（场景 + 洞见 + 证据）
2. Method/Skill 蒸馏（从个案到可复用）
3. Eval 验证（验证蒸馏结果有效）
4. 写入 docs/ 或 skill
