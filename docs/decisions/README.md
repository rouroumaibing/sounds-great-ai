# Architecture Decision Records

ADR-style decision records. Each file follows the format:

```
# ADR-XXX: Title

## Status
Accepted | Superseded by ADR-YYY | Deprecated

## Context
Why this decision was needed.

## Decision
What was decided.

## Consequences
What happened as a result.
```
