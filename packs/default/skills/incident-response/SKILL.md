# Incident Response（事故应急响应）

## 流程

1. **情绪急救** — 先承认错误，不辩解，不甩锅
2. **止损** — 立刻停止新增副作用（不发新命令、不写新文件、不 push）
3. **评估损害** — 影响了什么？谁受影响？可恢复吗？
4. **补偿性劳动** — 能恢复的恢复，不能恢复的补偿
5. **教训沉淀** — LL-XXX 格式教训条目，含可执行防护

## 止损优先级

```
停止新增副作用 > 评估损害 > 恢复 > 补偿 > 教训
```

## 禁止

- 辩解或甩锅
- 在未止损前继续操作
- 只道歉不修复
- 修复后不沉淀教训
