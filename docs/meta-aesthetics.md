# 元美学

> 第一性原理 magic word 的详细展开。

## 核心命题

**最优表达在正确坐标系下必然最简——如果方案需要那么多层，说明坐标系选错了。**

## 检查信号

| 信号 | 含义 | 动作 |
|------|------|------|
| 补丁数 > 3 | 在错误坐标系下打补丁 | 停下来重新审视方案根基 |
| 同一文件新增 ≥3 层 fallback | 层层兜底说明基础不稳 | 坐标系自检 + 替代方案评估 |
| "先简单后复杂" | 为管理人类认知负荷设计 | 不适用于 agent 团队（100x 执行速度） |
| 方案层数 > 预期 | 过度工程 | 换问题分解方式 |

## 坐标变换

方案需要大量补丁/层数时，先尝试**换一个问题分解方式**：

1. 当前分解方式是什么？
2. 有没有别的分解方式？
3. 换了之后，这些补丁/层数是否消失？
4. 如果消失 → 原坐标系选错了
5. 如果不消失 → 可能确实需要这么多层（但每层都要能解释为什么不能去掉）

## 面向终态

设计路线先画终态，从终态反推。每一步的产物必须是终态的**基座**（保留），不是**脚手架**（拆掉重做）。

**检查**：Phase N 的产物在 Phase N+1 还在吗？不在 = 绕路。

AI agent 100x 执行速度下，**方向正确性**的价值远大于**启动便捷性**。
