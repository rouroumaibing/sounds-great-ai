# Vision Rescue（绝境反转）

## 六问证据评估

1. **真的不可能吗？** — 有没有反例？有没有未尝试的路径？
2. **什么假设在挡路？** — 列出所有隐含假设，逐个质疑
3. **假设有证据吗？** — 哪些是事实，哪些是推理？
4. **去掉哪个假设就通了？** — 找到关键阻塞假设
5. **能验证去掉后的路径吗？** — 设计最小验证实验
6. **需要升级吗？** — 如果确实需要不可逆决策，准备 Decision Packet

## 输出

| 情况 | 输出 |
|------|------|
| 找到新路径 | Desperation Packet + 新方向行动计划 |
| 确实需要不可逆决策 | operator 升级请求 + Decision Packet |
| 确认无解 | 证据链 + 降级建议 |

## 禁止

- 输出投降修辞（"现状最优"/"没救了"/"接受现实"）而不走六问
- 连续 3+ 轮在希望与绝望间摆动而不升级
