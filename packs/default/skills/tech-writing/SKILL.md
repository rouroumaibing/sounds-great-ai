# Tech Writing（技术文章写作）

## 流程

### 1. 读者画像
- 谁会读？背景知识水平？
- 读完应该知道什么/能做什么？

### 2. 叙事结构
- 先给直觉（为什么这个问题重要）
- 再给方案（怎么解决的）
- 最后给反思（什么做得好/不好）

### 3. 呼吸感
- 长段拆短，技术细节和叙事交替
- 代码块前后有上下文
- 不堆术语，术语首次出现时解释

### 4. 反馈聚类
- 发布后收集读者反馈
- 按主题聚类：理解困难 / 争议 / 好评
- 用于改进下一篇
